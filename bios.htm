Bios Api v1
Sur cette page vous trouverez les instructions du bios pour la version v1

Pour communiquer avec le bios sur la v4 il faut utiliser "BAPI"
Qui permet de communiquer avec le bios. L'id de l'instruction est "29".
Le registre 1 sélection sera l'id de l'instruction bios et le registre 2 sera une valeur.
"BAPI {REG} {REG}"
Certains instructions bios peuvent interagir avec les registres, rom et la ram.


Voici la liste des instructions bios:

(1)
Cette instruction n'a pas d'entrée.
Cette instruction Met la version du bios dans le reg1 et la version du code dans reg2 (v1,v2....). Et la version des instructions v4 dans reg3.
